# MirDevAps Site

Site institucional estático da MirDevAps.

## Executar localmente

Abra `index.html` diretamente ou sirva a pasta com um servidor HTTP estático.

## Estrutura

- `index.html`: conteúdo e estrutura do site
- `styles.css`: identidade visual e responsividade
- `script.js`: menu móvel e animações de entrada
- `assets/`: marca e arte visual
